# ADRs

This folder stores architecture decision records for significant choices in the platform.

## Template

- [ADR template](./adr-template.md)
- [ADR 001: Internal Service Authentication](./001-internal-service-authentication.md)

## Suggested usage

When a design decision affects multiple services, APIs, infrastructure, or event contracts, create a new ADR with a short, decision-focused summary and record the tradeoffs.
